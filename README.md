# Gestion d'une association caritative (VB.NET)

Application de bureau (Windows Forms) pour gérer l'association « L'Espoir de La Vie » :
familles, adhérents, responsables, donateurs, dons, cotisations et comptabilité de base.

Projet académique réalisé à l'Institut Supérieur de Gestion de Tunis (ISG Tunis),
filière Informatique de gestion.

## Fonctionnalités
- Authentification (login / logout)
- Gestion des familles, des adhérents et des responsables
- Gestion des dons et des cotisations
- Fiche de contacts (donateurs et campagnes)
- Gestion comptable : liste des opérations et calcul du total des cotisations et des dons
- Ajout, modification et suppression des données
- Contrôle de saisie (adresses e-mail, montants)

## Technologies
- VB.NET, Windows Forms
- Visual Studio
- Stockage des données dans des fichiers texte (.txt)
- Contrôles : TextBox, ComboBox, DataGridView, DateTimePicker, RadioButton, PictureBox

## Lancer le projet
1. Cloner le dépôt ou télécharger le ZIP.
2. Ouvrir le fichier `.sln` avec Visual Studio (Windows).
3. Compiler et exécuter (F5).
4. Connexion de démonstration : `admin` / `admin123` (à adapter selon ton code).

Les fichiers de données (`familles.txt`, etc.) sont créés ou fournis à vide.
Les données du dépôt sont fictives.
